# Escuela María Auxiliadora · Sitio web

Sitio web de la **Escuela de Educación Básica María Auxiliadora** de **Julio Andrade, Carchi (Ecuador)**, que educa
"con el corazón para la vida" desde 1943. Da a padres de familia y a la comunidad un lugar para conocer la escuela,
encontrar admisiones y documentos, y entrar al portal de padres.

## Qué incluye

- Presentación de la institución y su lema.
- Enlaces rápidos: **Admisiones**, **Documentos** y **Portal de Padres**.
- Datos de contacto y ubicación.

## Detalles técnicos

| Capa | Tecnología |
|---|---|
| Framework | Next.js 15 (App Router) + React 19 |
| Lenguaje | TypeScript |
| Estilos | Tailwind CSS 4 |

El proyecto está dentro de la carpeta `my-app/`:

```bash
cd my-app
npm install
npm run dev      # http://localhost:3000
```

## In English

Website for María Auxiliadora elementary school in Julio Andrade, Carchi, Ecuador: school presentation and quick
links to admissions, documents and the parents' portal. Next.js 15, React 19, Tailwind CSS 4.
